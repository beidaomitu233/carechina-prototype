## 二、整体设计定位

### 2.1 视觉方向
- **受众**：**全体海外患者（所有国家/地区外籍人士）**，英文为默认语言，中文可切换。
- **气质关键词**：国际 · 可信 · 尊贵 · 温暖。避免医疗行业常见冷白蓝，改用**深翡翠绿 + 米白 + 鎏金**的东方质感配色。
- **字体**：标题用 `Fraunces`（人文衬线，兼具医学可信与奢华），正文用 `Work Sans`，阿拉伯语点缀用 `Tajawal`。
- **纹理细节**：Hero 与数据区叠加伊斯兰八芒星几何底纹（低透明度 SVG 平铺），呼应目标人群文化，同时视觉上"去 AI 味"。
- **动效**：首屏入场逐级渐显、滚动揭示（IntersectionObserver）、数据计数动画、等待周期对比条展开动画、合作医院跑马灯。

### 2.2 页面结构（自上而下）
1. 顶栏（导航 + 中英语言切换）
2. **Hero 首屏** —— 核心卖点（纯文案单列，v0.4 起移除示例卡）
3. 合作医院跑马灯
4. **平台核心优势展示区**
5. **症状 → 最优医院匹配区**（数据来自附件表格，可筛选）
6. **治疗方案区**（输入疾病 → 过往案例 + 推荐方案 + 中医体验）
7. **费用计算器区**（实时费用对比估算）
8. **就医流程展示区**（六步）
9. **数据概览区**（深色区块：指标 + 等待周期对比）
10. CTA 转化区 + 页脚

> **v0.2 结构变化**：上述内容由"整页滚动"改为 **8 个选项卡视图**（v0.93 起），通过顶部导航切换，每个视图独立呈现一个主题：
> - **Overview 概览** = Hero + 跑马灯 + 核心优势 + 快捷入口
> - **Hospital Matching 医院匹配** = 症状→医院匹配区
> - **Treatment Plan 治疗方案** = 输入疾病 → 过往案例 + 推荐方案 + 中医体验
> - **Cost Calculator 费用计算** = 实时费用对比估算
> - **How It Works 就医流程** = 六步流程
> - **Outcomes 数据概览** = 指标 + 等待对比
> - **TCM Guide 中医科普**（v0.93 新增独立视图，v0.95 移至末位） = 输入症状/病况 → 中医调治方案（辨证分型/方剂/穴位/食疗/养护）
> - **Free Consultation 咨询** = 页脚前独立咨询表单（顶部栏「联系我们」下拉面板承载联系信息 + 表单跳转）

## 三、业务要求落地对照

| 业务核心要求 | 设计稿落地区块 | 说明 |

### 6.4 关于"导航文字被划线"的排查指引
- **页面代码已确认干净**：用无头 Chromium 与用户同尺寸渲染，逐项 computed style 均为 `text-decoration: none`，像素级检测无贯穿横线；激活项的"下划线"是 `::after` 绘制的**金色指示条**（`bottom:-6px`，位于文字下方，非删除线）。
- 若在浏览器中仍看到删除线，请依次排查：
  1. **浏览器扩展**（最常见）：临时禁用翻译 / 划词 / 阅读 / 去广告类扩展（如沉浸式翻译、沙拉查词、Google Translate、Readwise 等），或用无痕/隐私窗口重新打开（无痕默认禁用扩展）。
  2. **浏览器辅助功能设置**：检查是否开启了"强制对文字加下划线/删除线"或自定义样式覆盖。
  3. 快捷键误触：Windows `Ctrl+Shift+X` / macOS `Cmd+Shift+X` 等会为选中文字加删除线标记。
- 本页已内置**双层兜底**（CSS `!important` + JS 内联 `!important` 运行时清理），只要页面本身加载正常，扩展注入也会被压掉。
